Sheet 02 — About & technical skills

Who’s on the drawing

The short version

I’m an Integrated M.Tech Data Science student at SRM IST, and most of my work lives one layer below the model — ingestion, transformation, schema, retrieval correctness.

I’ve built a version-aware index over 15,000+ legal documents, where the hard part was never the LLM — it was designing retrieval that knows which version of the law is the authoritative one. A local-first analysis service that keeps source code on the machine it came from. A primary field study of 147 workers, from the collection instrument through to the statistics. And a transformation layer turning raw industrial sensor streams into a model-ready feature set. Two of them became IEEE papers.

I prefer controlled comparisons over assumptions: identical inputs, identical metrics, every cell of the matrix directly comparable. And I write the thing down afterwards, so someone else can run it again.

— Deepika
